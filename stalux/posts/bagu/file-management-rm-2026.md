# 第四节：目录结构和文件管理指令：rm/-rf指令的作用是？

## 1. Linux 的目录结构

Linux 的文件系统是树形结构，最上面是根目录 `/`。

比如：

```bash
/usr/bin/rm
```

可以这样理解：

- 第一级目录是 `/`
- 第二级目录是 `usr`
- 第三级目录是 `bin`
- `rm` 是 `bin` 目录下的一个文件

这个路径叫绝对路径，也叫完整路径。

## 2. 绝对路径和相对路径

### 2.1 绝对路径

绝对路径是从根目录 `/` 开始写的路径。

例如：

```bash
/usr/bin/rm
```

特点是：

- 从 `/` 开始
- 每一层目录都写清楚
- 不依赖当前工作目录

### 2.2 相对路径

相对路径是以当前工作目录为基点的路径。

例如当前目录不同，`rm` 的相对路径也不同：

- 如果当前在 `/usr` 下，那么 `rm` 的相对路径可以写成 `bin/rm`
- 如果当前在 `/usr/bin` 下，那么可以写成 `./rm` 或 `rm`
- 如果当前在 `/usr/bin/somedir` 下，那么可以写成 `../rm`

这里：

- `.` 表示当前目录
- `..` 表示上一级目录

## 3. 当前工作目录相关命令

### 3.1 `pwd`

`pwd` 用来查看当前工作目录。

```bash
pwd
```

### 3.2 `cd`

`cd` 用来切换工作目录。

常见写法：

```bash
cd
cd .
cd ..
cd /usr/bin
```

可以这样记：

- `cd` 不带参数，一般回到当前用户的家目录
- `cd .` 不会发生变化，因为 `.` 表示当前目录
- `cd ..` 会回到上一级目录

## 4. Linux 里“很多东西都是文件”

Linux 有一个很重要的思想：很多资源都会被抽象成文件。

所以除了普通文件和目录，还会看到：

- 设备文件
- 管道文件
- `Socket` 文件
- 软链接文件
- 硬链接文件

这也是为什么很多工具都可以用统一方式处理它们。

## 5. 常见文件类型

常见文件类型可以先记这几种：

- 普通文件
- 目录文件
- 可执行文件
- 管道文件
- `Socket` 文件
- 软链接文件
- 硬链接文件

### 5.1 用 `ls -F` 快速看文件类型

```bash
ls -F
```

这个命令会在文件名后面带上一些标记，帮助判断类型。

例如常见标记：

- `/` 表示目录
- `*` 表示可执行文件
- `@` 表示软链接
- `=` 表示 `Socket`

## 6. `ls -l` 输出怎么看

```bash
ls -l
```

这个命令可以看到更详细的信息，比如：

- 文件类型和权限
- 硬链接数
- 所属用户
- 所属用户组
- 文件大小
- 修改时间
- 文件名

比如目录前面通常是：

```text
d
```

普通文件前面通常是：

```text
-
```

## 7. `touch`、`mkdir -p`

### 7.1 `touch`

`touch` 常用来创建一个空文件。

```bash
touch a.txt
```

### 7.2 `mkdir -p`

`mkdir -p` 可以递归创建目录。

```bash
mkdir -p hello/world
```

然后再配合：

```bash
touch hello/world/os.txt
ls hello/world
```

## 8. 查看命令帮助

### 8.1 `man`

`man` 是 `manual` 的缩写，用来查看命令手册。

例如：

```bash
man touch
man rm
```

### 8.2 `which`

`which` 用来查看一个命令文件所在的位置。

例如：

```bash
which rm
```

可能会看到：

```bash
/usr/bin/rm
```

## 9. 查看文件内容

### 9.1 `cat`

`cat` 适合快速查看文件内容。

例如：

```bash
cat /etc/hosts
```

### 9.2 `more`

`more` 适合分页看内容较长的文件，但功能比较基础。

### 9.3 `less`

`less` 和 `more` 类似，但更常用。

可以直接记：

- `less` 比 `more` 更灵活
- `less` 支持向上翻页

### 9.4 `head` 和 `tail`

`head` 和 `tail` 用来查看文件的头部或尾部若干行。

例如：

```bash
head -n 10 a.log
tail -n 10 a.log
tail -f nginx.log
```

其中：

- `head` 看前面几行
- `tail` 看后面几行
- `tail -f` 常用来实时看日志

## 10. 查找和过滤

### 10.1 `grep`

`grep` 用来按条件搜索文本内容。

比如看某个 IP 的 `nginx` 日志，或者看某段时间附近的日志内容，都可以用 `grep`。

### 10.2 `find`

`find` 是通用的查找文件命令。

例如：

```bash
find /etc -name hosts
```

## 11. `rm`、`rm -r`、`rm -rf` 的作用

### 11.1 `rm`

`rm` 是删除命令，默认用于删除文件。

例如：

```bash
rm a.txt
```

如果对目录直接使用：

```bash
rm hello
```

通常会报错，因为目录不能这样直接删。

### 11.2 `rm -r`

`-r` 是 `recursive`，表示递归删除。

也就是：

- 如果目标是目录，就进入目录内部
- 把里面的内容一层一层删掉
- 最后再删目录本身

例如：

```bash
rm -r hello
```

### 11.3 `rm -f`

`-f` 是 `force`，表示强制。

可以先记住它的作用：

- 删除时尽量不提示
- 遇到不存在的文件时不报错

它常常和 `-r` 一起用。

### 11.4 `rm -rf`

`rm -rf` 就是：

- `rm`：删除
- `-r`：递归删除目录
- `-f`：强制执行，尽量不提示

所以：

```bash
rm -rf hello
```

表示把 `hello` 这个目录及其里面所有内容强制递归删除。

## 12. 为什么 `rm -rf /` 很危险

这里：

- `/` 是根目录
- `rm` 是删除
- `-r` 是递归
- `-f` 是强制

所以：

```bash
rm -rf /
```

字面意思就是从根目录开始，把整个文件系统里的内容递归强制删除。

这也是它危险的原因。

## 13. 这一节先记住的点

- 根目录是 `/`
- 绝对路径从 `/` 开始，相对路径以当前工作目录为基准
- `pwd` 看当前目录，`cd` 切换目录
- Linux 里很多资源都会被抽象成文件
- `ls -F` 适合快速看文件类型，`ls -l` 适合看详细信息
- `cat`、`more`、`less`、`head`、`tail` 都是查看文件内容的常用工具
- `which` 查命令位置，`find` 查文件，`grep` 查文本
- `rm` 删文件，`rm -r` 递归删目录，`rm -rf` 是强制递归删除
